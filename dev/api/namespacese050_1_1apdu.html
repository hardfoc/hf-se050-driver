Build a CASE 3/4 short command when data_len ≤ 255 and a 1-byte Le is enough.

Layout: CLA INS P1 P2 Lc [data...] [Le]. If le_present is false, the Le byte is omitted (CASE 3). If le_present is true, le is appended (CASE 4 short).
