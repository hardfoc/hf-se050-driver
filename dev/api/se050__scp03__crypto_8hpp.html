Detailed Description

Host AES-128 / RFC 4493 CMAC / GlobalPlatform SCP03 KDF (header-only).

This is the host-side primitive set the SE050 T=1 stack needs so I²C1 can run an authenticated SCP03 channel. It is not NXP Plug & Trust and does not contain NXP default platform keys.

Derivation layout matches GP Card Spec Amendment D (label || 00 || L || counter || host_challenge || card_challenge).
