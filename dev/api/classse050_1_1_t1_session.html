Exchange a raw information field payload (APDU bytes) with the SE using I-blocks.

Performs chained transmission/reception per ISO 7816-3 (R-block ACK between chained blocks).

Parameters
cmdCommand INF (typically a full C-APDU).
cmd_lenLength of cmd (may exceed t1::kMaxInformationField; chaining used).
rspBuffer for concatenated response INF (typically R-APDU body + status).
rsp_capCapacity of rsp.
rsp_lenTotal INF bytes stored into rsp.
Note
If this returns any error other than Error::Ok, call ResetSequenceState (or perform a warm / electrical reset) before the next exchange — N(S) / N(R) state may no longer match the SE.
