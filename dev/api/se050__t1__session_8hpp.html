Detailed Description

ISO/IEC 7816-3 T=1 block protocol for NXP SE050 T=1 over I²C (EDC = CRC-16).

This layer sits on top of I2cTransceiveInterface and implements:

  • NAD discipline (0x5A host → SE, 0xA5 SE → host),
  • I-block send/receive with chaining (M bit, 0x20),
  • R-block ACK between chained blocks (0x80 family),
  • error recovery per ISO/IEC 7816-3 11.6.3: an invalid block from the SE is answered with an R-block asking for it again, an R-block NACK from the SE makes the host send its last I-block again (up to SetMaxRetransmissions times),
  • the SE's IFSC from the ATR / profile (GetAnswerToReset) as the command block size,
  • the start-up read of SE050 erratum I2C.1 (RecoverAfterHostReset),
  • minimal S-block requests used during bring-up (0xC6 warm reset, 0xC7 GET ATR),
  • CRC-16 EDC via se050::crc.
Note
Field firmware may require tuning SetInterFrameDelayMs. Align behaviour with NXP UM11225 / UM1225 and validate on-target (logic analyser / golden traces).
