Detailed Description

SE050 applet selection helpers (ISO 7816-4 SELECT by DF name / AID).

The default AID bytes mirror the NXP Plug & Trust / mbed SE05x IoT applet convention. Always confirm the correct AID for your OEM OS build using NXP tooling (se05x_GetInfo) or your secure manufacturing database.
