Compare two byte strings in time that depends only on len, not on where they differ.

Use for MACs and cryptograms: memcmp returns at the first differing byte, which lets an attacker who can time the answer forge a MAC byte by byte.

◆ SecureZero()

void se050::scp03::crypto::SecureZero ( void *  p,
std::size_t  len 
)
inlinenoexcept

Overwrite len bytes at p with zeros in a way the compiler cannot drop.

Stores go through a volatile pointer and a compiler barrier follows, so the wipe survives dead-store elimination even when the buffer is never read again (the explicit_bzero / memset_s pattern). Use it for session keys, round keys, MAC subkeys and key-derived intermediates.
