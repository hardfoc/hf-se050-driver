Build GP PUT KEY (CLA 0x80, INS 0xD8, P1 = key version, P2 0x81).

Replaces ISD key set key_version (product: 0x0B) with new_enc, new_mac, new_dek. The current DEK encrypts the new key values. Caller must have an open SCP03 session with the current set. Never embeds NXP default key bytes.

Parameters
expect_rspVersion byte + three 3-byte KCVs the card must echo.

One AES key field inside GP PUT KEY (encrypted with the current DEK).

Layout matches NXP ex_se05x_rotate_scp03_keys: type 0x88, KCV = first 3 bytes of AES-ECB(plain, 0x01×16). This is GPCS B.2.1 AES-ECB of a 16-byte key with the current DEK (NXP ex_se05x_rotate_scp03_keys). It is not RFC 3394 AES Key Wrap (that wrap is ADR-0054 sec_rpc / image KEK). Do not substitute.

C-MAC + C-ENC wrap of a short C-APDU (this C2 rejects extended Lc).

Caller owns out. On CM4 put out in D2 .se_apdu_scratch. Updates MCV. Does not increment the command counter (host increments in UnwrapResponse after the card replies).
