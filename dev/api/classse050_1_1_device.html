std::size_t *  rapdu_len,
std::uint32_t  timeout_ms

inlinenoexcept

Transmit a C-APDU (already serialized) and receive the R-APDU INF bytes.

When Scp03 is open, C-MAC/C-ENC wrap and R-MAC/R-ENC unwrap using the bound scratch. Otherwise plaintext T=1 (honest posture without unique keys). A response without a valid R-MAC returns Error::Authentication; so does a T=1 failure inside the channel (returned as the T=1 error). Either way the channel is closed with its keys wiped, and further calls return Error::Authentication until Scp03().Close() or a new OpenSecureChannel().

Parameters
capduSerialized command APDU.
capdu_lenLength of capdu.
rapdu_bufBuffer for concatenated response body + SW1SW2.
rapdu_capCapacity of rapdu_buf.
rapdu_lenWritten length on success.
