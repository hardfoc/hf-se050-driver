HF-SE050 documentation

This site tracks the docs/ folder for the NXP SE050 / SE050A secure element driver. It focuses on practical bring-up, object management, onboarding flows, and production security patterns.

Structure

  1. Installation — Toolchain, repo layout, and local Doxygen build
  2. Quick start — Planned bring-up flow
  3. Hardware setup — I²C and board notes
  4. CMake integration — hf::se050 and ESP-IDF component
    4b. Platform integration — CRTP I2C transport and hf-core Se050Handler
  5. API reference — Transport, session, device templates
  6. Examples — All ESP32 example flows + internal diagrams
  7. Troubleshooting — Common issues while developing
  8. Security flows (IoT / OTA / Comms) — End-to-end trust and channel models with SE050
  9. Datasheet & links — Official NXP pointers; local PDFs stay out of git
