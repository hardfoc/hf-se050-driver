Platform integration (CRTP transport)

The driver is built around **se050::I2cTransceiveInterface<Derived>** — compile-time polymorphism with zero virtual calls, matching other hf-*-driver repos.

Handler layer (hf-core)

**Se050Handler** (in hf-core) mirrors **Fdo2Handler**: it wraps **BaseI2c** and optional **BaseGpio** (SE_RESET) in **HalI2cSe050Comm** implementing **se050::I2cTransceiveInterface**, adds **RtosMutex**, and owns **se050::Device<HalI2cSe050Comm>**. Enable with **HF_CORE_ENABLE_SE050** before including hf_core_build_settings.cmake. On ESP32, from hf-core/examples/esp32/scripts, run ./build_app.sh se050_handler_test Debug. HAL integration and reset semantics are documented in hf-core under **docs/handlers/se050_handler.md** (see the published hf-core docs).
