Detailed Description

GlobalPlatform SCP03 session over an existing T=1 I²C link.

Protects on-board APDUs against an I²C probe (the MitM that can forge "signature valid"). This is not the HMI channel — HMI trust remains SE-backed TLS 1.3. Host crypto is in se050_scp03_crypto.hpp (AES-CMAC / CBC). Compiled-in NXP default ENC/MAC/DEK values are forbidden; OpenSecureChannel returns Error::NotSupported when static keys are absent.

Wrap/unwrap uses caller-owned buffers (CM4: D2 .se_apdu_scratch). Live T=1 exchanges stay plaintext until unique ENC/MAC keys exist.
