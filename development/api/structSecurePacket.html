Detailed Description

Simplified packet shape used on the wire.

Layout (all fields big-endian): [ counter : 4 bytes ] – monotonic, used for anti-replay. [ nonce : 12 bytes ] – TRNG-sourced freshness. [ payload : N bytes ] – application data (here: ASCII text). [ sig_der : 70–72 B ] – ECDSA(P-256, SHA-256) signature over the concatenation of the three fields above.

In a production protocol you would also add a 1-byte version tag and a 4-byte key_id so the receiver can pick the right verification key.
