Dispatch a command blob received from the cloud.

Layout: byte[0] = CommandId byte[1..] = command-specific payload (already includes any inner signature for the command, verified inside the branch)

Returns true if the command was well-formed AND successfully acted upon. Failure is not an error path — signed-command rejection is the expected hostile case and we log + drop on the floor.
