Detailed Description

RFC 3394 AES Key Wrap / Unwrap with a caller-supplied AES-128 block.

The wrapping key never needs to exist in MCU RAM: the 16-byte encrypt/decrypt callbacks may be SE050 CipherOneShot AES-ECB (AN12413 P1_CIPHER / P2_ENCRYPT_ONESHOT|P2_DECRYPT_ONESHOT) or a host software AES. AES-256 CEK wrap is 40 bytes (4 × 8-byte semiblocks plus the 8-byte integrity IV).
